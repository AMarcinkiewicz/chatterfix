How it works

No delay

Real keystrokes pass straight through. No buffering, no lag, no change to how typing or gaming feels.

No keylogging

It checks timing, not what you type. Nothing is logged or stored, and the source is public.

Your call

Set the sensitivity, see which keys chatter, pause it, or launch it at login. All from the menu bar.

Install in under a minute

macOS

  1. Open the .dmg and drag ChatterFix into Applications.
  2. First launch: right-click the app and choose Open to get past the "unverified developer" notice.
  3. Allow Accessibility when asked. Filtering starts on its own.
Download for macOS

Windows

  1. Run ChatterFix.exe. No installer.
  2. If SmartScreen appears, click More info, then Run anyway.
  3. It lands in the system tray and starts working right away.
  4. Turn on Start at Login from the tray menu to run it every boot.

Questions

Does it record what I type?

No. It only checks key timing to spot a bounce, and stores nothing. The code is public if you want to confirm it.

Will it add lag or affect gaming?

No lag. Real presses pass instantly, and held keys or different-key combos are never touched. The only edge case is tapping one key faster than the threshold, which you can lower before playing. Games with kernel-level anti-cheat read input below ChatterFix, so it does not apply inside those.

Which keys does it fix?

Any normal key. The Blocked Keys list shows which of yours are misbehaving. Modifier keys like Shift and Ctrl are not filtered, but chatter on those is rare.

It caught a real double letter. What do I do?

Lower the sensitivity one step. If chatter still gets through, raise it one step. Standard (50 ms) suits most keyboards.

Is it really free?

Yes. Free and open source under the MIT license. No ads, no account, no upsell.

How do I remove it?

On macOS, quit it and drag ChatterFix to the Trash. On Windows, quit it and delete the .exe. Nothing is left behind.
