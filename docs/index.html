How it works

It adds no delay

Every real keystroke passes straight through. Nothing is buffered or held back, so typing and gaming feel exactly the same.

It never reads what you type

ChatterFix only looks at timing, which key and how long since it was last released. It keeps none of it, and the full source is public.

You stay in control

A small menu lets you set how aggressive it is, see which keys are chattering, pause it, or launch it at login.

Install in under a minute

macOS

  1. Download the .dmg and open it.
  2. Drag ChatterFix into Applications, then open it.
  3. The first time, macOS shows an "unverified developer" notice because the app is not signed with a paid certificate yet. Right-click the app and choose Open to run it.
  4. Allow the Accessibility permission when asked. Filtering starts on its own.

Windows

  1. Download and run ChatterFix.exe. There is no installer.
  2. If SmartScreen appears, click More info, then Run anyway. The warning shows only because the app is not signed yet.
  3. ChatterFix appears in your system tray and starts working right away.
  4. Open the tray menu and turn on Start at Login if you want it every boot.

Questions

Does it record what I type?

No. ChatterFix only looks at the timing of key presses to spot a bounce. It does not log, store, or send your keystrokes anywhere. The code is public if you want to confirm this.

Will it add lag or affect gaming?

No added lag. Real presses pass through instantly, held keys are never touched, and it only ever compares a key against itself, so fast typing across different keys is fine. The one edge case is deliberately tapping the same key faster than the threshold, which you can lower before a session. Note that games with kernel-level anti-cheat read input below where ChatterFix sits, so it does not apply inside those.

Which keys does it fix?

Any normal key that chatters. Open the Blocked Keys list in the menu to see exactly which keys on your keyboard are misbehaving. Modifier keys like Shift and Ctrl use a different path and are not filtered, but chatter on those is rare.

It caught a real double letter. What do I do?

Lower the sensitivity one step. If chatter still slips through, raise it one step. Standard (50 ms) works for most keyboards.

Is it really free?

Yes. Free to download, free to use, open source under the MIT license. No ads, no account, no upsell.

How do I remove it?

On macOS, quit it from the menu and drag ChatterFix from Applications to the Trash. On Windows, quit it from the tray and delete the .exe. It leaves nothing else behind.
